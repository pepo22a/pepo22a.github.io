# English Premier League Guide

## Project Overview

I am Abanob Hanna, and this is my third and final project for my COMP 3301 class. I decided to create a two-page website project that introduces new fans to English Premier League, and give them some information about the history and current format of the competition. The project provides some information about the Premier League top 5 clubs.
## Live Website

[English Premier League Guide](https://pepo22a.github.io/)

## Website Pages

- Home: An introduction to the league and its history.
- About: The competition current format and top 5 clubs history.
