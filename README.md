# Personal Introduction Website

This is my personal introductory website, where I discuss my university major and explain why I chose it, specifically after a hiatus caused by severe health issues. I also outline my post-graduation goals, focusing on my desire to use technology to help people with mobility impairments lead their lives as easily as possible. Additionally, I share details about my top three hobbies. This website serves as a practical exercise to apply what I learned this semester regarding website structuring (using HTML) and styling (using CSS), as well as project planning and tracking via GitHub and its commit system, which allows for monitoring changes step-by-step throughout the project.
