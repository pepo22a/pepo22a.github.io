# Project Plan

My goal is to build a two-pages website that introduces visitors to the English Premier League. The homepage will explain the league and feature brief introductions about the competition and its history. The About page will explain the Premier League current format, prominent clubs, and a breif introduction about each club history in the competition. Both pages will use one external stylesheet .

## Deliverables and Boundaries

- index.html: A homepage with a league introduction and selected club information.
- about.html: A second page explaining the website and its audience.
- style.css: One shared stylesheet for consistent formatting.
- docs/scope.md: The revised scope statement.
- docs/plan.md: This risk analysis and task schedule.
- docs/retrospective.md: A reflection written after the project work.
- README.md: A clear repository introduction with website and documentation links.
- A public GitHub repository, a live GitHub Pages website, screenshots of both live pages, and a complete submission ZIP.

 The website will not have live scores, user accounts, ticket sales, and databases are outside the project scope. 
## Risk Analysis Using TAME
