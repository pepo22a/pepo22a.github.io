# Project Scope Statement: English Premier League Guide

## Project Purpose

In this project, I will apply all the skills I have learned from planning, documenting, building, and deploying a website. The website aims to introduce people to my favorite hobby, which is soccer, specifically, watching the English Premier League, which is considered the best league in the world. It will explain exactly what the league is and how you can start following it if you are interested.

## Description

I will create a two-page website hosted in a public GitHub repository. The repository will include a README.md file and three additional files stored in the docs/ folder: plan.md, scope.md, and retrospective.md. It will also contain three main files: index.html for the home page, about.html for the second page, and style.css to style both HTML pages. The website focuses on the English Premier League. The home page will outline the site's purpose, in addition to introducing visitors to the Premier League and its fascinating history, and direct them to the second page, which covers the competition's current format, key features, prominent clubs, and their titles.

## Desired Results

- A two-page website consisting of a homepage (index.html) and a second page (about.html) running smoothly 
- A style.css file that gives both pages a good style
- A public GitHub repository (pepo22a.github.io) containing all required files
- A professional README.md that contains a link to the live website 
- A docs/scope.md file revised after peer feedback
- A docs/plan.md file with a TAME risk analysis and task schedule
- A docs/retrospective.md file discussing what went well, what went wrong, and what I would do change if I had the opportunity to do so 

## Exclusions

The website will not work as an official Premier League website that includes live scores, updated standings, user accounts, or information pages for every club.
